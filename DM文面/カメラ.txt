コメントありがとうございます。夕暮れの港を3DCGで作り、カメラを3回動かす動画の手順書です。Blender で港を組む所から書き出しまで、10段の手順すべてに Claude Code に渡す指示文が入っています。

〔作りたい題材〕を自分の題材に替えて、空のフォルダで開いた Claude Code に次の1行を貼ってください。
https://yuma-ai-works.pages.dev/s/k13.md を curl -fL で 手順書.md に保存して、全部読んでから、〔作りたい題材〕で同じ型の動画を作って

向いているのは、真ん中に高い物が1つ、その後ろに大きな光がある題材です（例：雪の夜の駅と時計塔）。作業はパソコンで、Blender と VOICEVOX も使います。Claude Code は有料です。
